# Screenshots

The README references four images from this directory. They are not committed yet.

| File | What to capture |
|---|---|
| `links.png` | The links index with a decent number of links, tags visible, and a filter applied |
| `link-detail.png` | A single link showing fetched metadata — preview image, description, tags |
| `smart-group.png` | A group whose contents come from tag rules, with the rules visible |
| `api-tokens.png` | Settings → API tokens, with a token freshly created (**redact the token value**) |

Guidelines:

- Capture at a 1280–1440px viewport width so text stays readable when GitHub scales them down.
- Use light mode for consistency, unless a pair of light/dark shots is genuinely more useful.
- Seed realistic-looking data. Screenshots of `Lorem ipsum` bookmarks read as a demo, not a product.
- **Check for personal data before committing** — real email addresses, private URLs, or an
  unredacted API token are permanent once pushed.
