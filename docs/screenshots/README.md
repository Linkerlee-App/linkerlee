## If you replace these

- Capture at a 1280–1440px CSS viewport. Retina (2×) files are fine — GitHub scales them down
  and they stay sharp.
- Light mode, for consistency with the existing set.
- **Check for personal data before committing.** Real email addresses, private URLs, and
  anything that looks like a token are permanent once pushed. The API tokens page is safe to
  show — it lists token *names* and timestamps, never values — but a freshly created token
  displays its value once, so do not capture that moment.
